# Taschenrechner in Python

Ein interaktiver Befehlszeilen-Taschenrechner, entwickelt in Python. Dieses Projekt wurde erstellt, um grundlegende Programmierkonzepte wie Schleifen, Funktionen, Benutzereingaben und Fehlerbehandlung zu demonstrieren.

## Funktionen
•⁠  ⁠Grundrechenarten: Addition, Subtraktion, Multiplikation, Division
•⁠  ⁠Erweiterte Operationen: Potenzieren ($x^y$) und Quadratwurzel ($\sqrt{x}$)
•⁠  ⁠Fehlerbehandlung (z. B. Division durch Null oder falsche Eingaben)
•⁠  ⁠Interaktives Menü mit Benutzerschleife

## Verwendung
Um den Taschenrechner auszuführen, stellen Sie sicher, dass Python installiert ist, und führen Sie folgenden Befehl aus:

```bash
python taschenrechner.py
